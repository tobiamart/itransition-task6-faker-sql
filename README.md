# Task 6 – Faker SQL: fake user generator in PostgreSQL stored procedures

- **Application:** https://faker-sql-generator.vercel.app
- **Library documentation:** [docs/FAKER_SQL.md](docs/FAKER_SQL.md) (also served at https://faker-sql-generator.vercel.app/docs)

A web application that generates random but reproducible fake contact data. All data generation
is implemented as PostgreSQL stored functions and procedures in the `faker` schema; the Python
(Flask) app only calls `faker.generate_users(locale, seed, batch, size)` and renders the rows.

- Locales: English (US), German (Germany), Polish (Poland); a new locale is data only.
- Per user: full name with variations (title, middle name or initial, suffix, academic degree,
  double surname), localized address with variations, geolocation uniform on the sphere,
  height and weight from normal distributions, eye and hair colour, phone number in several
  formats, e-mail address.
- The same locale, seed, batch number and index always give the same user.

## Structure

```
sql/01_schema.sql          tables (one names / words / formats / regions table for all locales)
sql/02_functions.sql       the faker library: RNG, sampling, templates, field generators, entry points
sql/03_data.sql            lookup data, generated by tools/build_data_sql.py
docs/FAKER_SQL.md          documentation of every function and algorithm
app.py                     Flask app (deployed on Vercel as a Python function)
templates/                 HTML templates
tests/test_faker_sql.py    tests: reproducibility, distributions, completeness
tools/setup_db.py          installs the schema, functions and data into a database
```

## Run locally

```bash
python -m venv .venv && .venv/Scripts/pip install -r requirements.txt pgserver faker
python tools/setup_db.py            # uses $DATABASE_URL or a local embedded PostgreSQL (pgserver)
python app.py                       # http://localhost:5000
python -m unittest discover tests
```

## Benchmark

| Environment | en_US | de_DE | pl_PL |
|---|---|---|---|
| Neon free plan (PostgreSQL 18, ARM), run from the deployed app | 3,664 users/s | 3,918 users/s | 4,032 users/s |
| Local PostgreSQL 16 (Windows, x86-64) | 3,634 users/s | 3,928 users/s | 4,009 users/s |

20,000 users per locale in one `faker.benchmark(locale, 20000)` call, time measured inside the database.
Run it yourself on the [Benchmark page](https://faker-sql-generator.vercel.app/benchmark) or with
`SELECT * FROM faker.benchmark('en_US', 20000);`.
